* Introduction

Tiny dictionary for nepali word and meaning search.

* Installation and Use

Unzip the `sabdakosh.json.gz` into `sabdakosh.json`, this is gzip compressed.

```bash
gzip -d sabdakosh.json.gz
```

Run the application through
`cargo run --release`

The application assumes the `sabdakosh.json` is in the same directory. I might just include it in the binary in the future.

* Fancy Features

If you have aspell set up with nepali language. Then when it can not find an exact match, it can communicate with aspell to get the root word and show the meaning for that instead.

To set up aspell with nepali language, goto [[https://github.com/Atreyagaurav/aspell6-ne][`aspell-ne` repo]].
